# 🚀 Инструкция: Как бесплатно выложить сайт онлайн и добавить его в поиск Яндекса и Google

Этот документ подробно описывает, как бесплатно опубликовать проект **SIMUP 2.0** в интернете и бесплатно зарегистрировать его в поисковых системах **Яндекс** и **Google (Google Chrome)**.

---

## 1. Где и как бесплатно выложить сайт в интернет

Чтобы сайт появился в поиске, он должен быть доступен по публичному веб-адресу (URL с HTTPS). Вот 2 самых простых и 100% бесплатных способа:

### Вариант А: GitHub Pages (Прямо из вашего репозитория — 2 минуты)
Поскольку ваш проект уже находится в репозитории на GitHub:
1. Откройте ваш репозиторий: `https://github.com/kipsway/simup`
2. Перейдите во вкладку **Settings** (Настройки) в правом верхнем углу репозитория.
3. В левом боковом меню выберите пункт **Pages**.
4. В разделе **Build and deployment**:
   - В выпадающем списке **Branch** выберите ветку `main`.
   - Папку оставьте `/ (root)`.
   - Нажмите кнопку **Save** (Сохранить).
5. Через 1–2 минуты страница обновится, и вверху появится зеленая плашка с вашим готовым бесплатным адресом сайта:
   `https://kipsway.github.io/simup/`
   *(Сайт сразу работает по защищенному протоколу HTTPS и с быстрым бесплатным CDN).*

### Вариант Б: Vercel (Мгновенное развертывание и быстрый хостинг)
1. Перейдите на сайт [vercel.com](https://vercel.com) и зарегистрируйтесь бесплатно через аккаунт GitHub.
2. Нажмите кнопку **Add New...** -> **Project**.
3. Выберите ваш репозиторий `simup` из списка и нажмите **Import**.
4. Нажмите синюю кнопку **Deploy**.
5. Через 20 секунд сайт готов и доступен по адресу вида: `https://simup.vercel.app` (также абсолютно бесплатно с автообновлением при каждом `git push`).

## 2. Как добавить сайт в Яндекс (Яндекс Поиск)

Чтобы сайт индексировался и находился в Яндексе:

1. Откройте [Яндекс Вебмастер](https://webmaster.yandex.ru/) и войдите под вашим Яндекс-аккаунтом.
2. Нажмите кнопку **Добавить сайт** (значок «+»).
3. Введите адрес вашего сайта (например: `https://kipsway.github.io/simup/` или ваш домен на Vercel) и нажмите **Добавить**.
4. Яндекс предложит подтвердить права на сайт:
   - Самый простой способ — **Метатег**.
   - Скопируйте код мета-тега вида:
     `<meta name="yandex-verification" content="ВАШ_КОД" />`
   - Вставьте этот код в файл `index.html` внутри тега `<head>` (там уже есть заготовка `name="yandex-verification"`).
   - Нажмите кнопку **Проверить** в Яндекс Вебмастере.
5. После подтверждения перейдите в левом меню в:
   - **Индексирование** -> **Файлы Sitemap**.
   - Вставьте адрес: `https://ваш-сайт/sitemap.xml` и нажмите **Добавить**.
6. Перейдите в **Индексирование** -> **Переобход страниц** и отправьте главную страницу на переобход.
7. В течение нескольких дней роботы Яндекса проиндексируют сайт, и он начнет появляться в поиске.

## 3. Как добавить сайт в Google (Google Chrome и Google Поиск)

1. Откройте [Google Search Console](https://search.google.com/search-console).
2. Нажмите **Добавить ресурс**:
   - Выберите вариант **Префикс URL** (справа).
   - Введите полный адрес сайта: `https://kipsway.github.io/simup/`
   - Нажмите **Продолжить**.
3. Подтвердите владение сайтом:
   - Выберите способ **Тег HTML** (мета-тег в `<head>`).
   - Скопируйте код вида: `<meta name="google-site-verification" content="ВАШ_КОД" />`
   - Вставьте его в `index.html` (там уже есть заготовка `name="google-site-verification"`).
   - Нажмите **Подтвердить**.
4. В левом меню выберите **Файлы Sitemap**:
   - Введите `sitemap.xml` и нажмите **Отправить**.
5. Вверху в строке «Проверить URL на ресурсе» вставьте адрес главной страницы и нажмите клавишу Enter, затем нажмите кнопку **Запросить индексирование**.

## 4. Что уже настроено в коде SIMUP 2.0 для идеального SEO:

- **`robots.txt`**: содержит директиву `User-agent: * Allow: /` и ссылку на карту сайта `sitemap.xml`.
- **`sitemap.xml`**: XML-карта сайта с датой обновления и приоритетом.
- **Мета-теги в `index.html`**:
  - Четкий заголовок `<title>` с ключевыми словами (CS2, Dota 2, Rust, апгрейд скинов).
  - Уникальный `<meta name="description">` и `<meta name="keywords">`.
  - Микроразметка **OpenGraph** для отображения сниппетов в Telegram, VK и соцсетях.
  - Структурированные данные **Schema.org WebApplication** для расширенных сниппетов в поиске.
  - Канонический тег `<link rel="canonical">`.
